## DATAREPO-69.2: the small-search exception (yes, read results.txt)

The search task's results.txt holds one PEP block (`Metrics for Determination of PEP Using Binary Classification`).
These lines, verbatim from master, decide it:

| results.txt | `iterative` |
|---|---|
| `*       Training Rounds Run:  <n>` inside the PEP block | `on`: it iterated (n can be 1, when round 1 was rejected and round 0 kept) |
| `Iterative PEP training was not run: too few peptides to train at peptide level, and PSM-level folds can split one sequence between training and held-out data. PEP was trained once.` | `off`: your small-search row |
| a PEP block with neither line | `off`: trained once. Iteration off writes exactly the block from before iteration existed |
| no PEP block | PEP did not train, so the field describes nothing. Record whatever you record for an untrained PEP column |

On 1.1.11 and earlier only the last two rows can occur, so the same reader works for every release.
