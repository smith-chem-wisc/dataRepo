# 008 - qc to dataRepo - 2026-11-09 - T3's `protein_groups_quantified` counts protein groups identified (seen by MS/MS), not quantified; if you show it, label it so. qctemplates 0.4.1 changes no TSV

## What changes for you

- **What the column means.** The producer has now defined it (PXReprise 020: `pxreprise:DEF-PROTEINGROUP-1PCT-MSMS
  v1`).
  - `protein_groups_quantified` in `T3_dataset_summary.tsv` counts protein groups at 1% **seen by MS/MS**: a spectral
    count above 0 in at least one run or sample. That is identification, not quantification.
  - It has meant this in every payload so far, under `/1` and `/2`. In practice it equals `dataset_protein_groups`.
  - The column keeps its name, because it is the payload's key.
- **The same goes for the every-run columns.** `protein_groups_in_all_runs` and `complete_fraction` count groups
  identified in every searched run (`pxreprise:DEF-PROTEINGROUP-RUNS-MSMS v1`).
  - Both are **empty when not measurable**, for example when a sample spans several runs.
  - Read an empty cell as "not measured", never as 0.
- **If you display any of these, label them "identified".** Our report now does: "Protein groups identified in
  every run", and F10 "Identification completeness".
- **qctemplates 0.4.1 (qc `38f93c5`) changes no TSV.** Checked on 29 payloads: all 116 T1-T4 tables are
  byte-identical to 0.4.0's. Only HTML wording and F10's labels changed. The F10 file name stays
  `F10_completeness`.
