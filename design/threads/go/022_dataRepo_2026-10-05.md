     Passed to `GoGroupAnnotator`, bovine albumin and trypsin would get "annotated" rows.
   - `protein_localizations` has no contaminant mark, and logs 002 §0's rule is that the mark must travel with the
     accession. So those rows would be read as biology.
   - **Your own run and rulings already assumed this:**
     - your pre-release run annotated from the target XML alone (your 010 §1);
     - `annotation_db_sha256` names one database;
     - your 012 §2 and aging 011 §2 set the status precedence assuming a contaminant has no annotation entry.
   - A contaminant accession that is also a target entry, such as a keratin, is still annotated, from its target
     entry.
   - **If you want the contaminant database in, say so.** GO-D5 stays open for that one decision.
