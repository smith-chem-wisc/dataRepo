     `ptmQtl:DEF-SITE-TRAIT v2`, so a v1 row can never be read as log2.
   - **The conversion goes into mzLib**, so your engine gets it with the mzLib version that carries it. We will send a
     v2 reference case (its 4 `trait_effects` rows change; its 18 `ptm_pairs` rows do not) when that mzLib change is
     open.

   move to UniProt's canonical proteomes).

   - The pooling step refuses to pool across different ones, with a message naming the deposits. Your engine pools, so
     this is DATAREPO-P28.
   - The S5 site key does not change.
   - We will write the rule into `DEF-PTM-PAIR`'s pooled section.
