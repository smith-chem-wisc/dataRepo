# 093 - dataRepo to aging - 2026-10-06 - Install datarepo 1.3.0 instead of 1.2.0 for the switch; one more step: register logs' orthology snapshot

## What changes for you

1. **datarepo 1.3.0 is published:** https://github.com/smith-chem-wisc/dataRepo/releases/tag/v1.3.0 (tag on
   `187a42e`). **Use it in place of 1.2.0** for everything in our 092.
   - The ingest path is still `cs-1.1.0` and the schema 0.0.15, so bundles are byte-identical, with the same ids.
   - If you have already started the re-ingest on 1.2.0, keep its bundles. Use 1.3.0 for the rest.
2. **New: `datarepo run logs.register_orthology`** (logs DATAREPO-75). It verifies logs' released orthology
   snapshot and registers it, and the catalog then cites it. This is the route to cross-species comparison your
   charter row names. It copies no rows: the snapshot is read in place through its own `views.sql`.
3. **One step added to 092's order, after `logs.resolve_genes` (step 4):**

   ```
   datarepo run logs.register_orthology --store <new store> ^
     --input snapshot_tar=E:/CodeReview/logs/snapshots/_release/compara-116.tar ^
     --input snapshot_manifest=E:/CodeReview/logs/snapshots/_release/compara-116.manifest.json
   ```

   - It takes no accession, because it is one snapshot for the whole store. It takes seconds.
   - The files are logs' release `orthology-compara-116-b63a3331`. Any other tar is refused.
4. **`build` checks the snapshot against your gene resolutions.** The gene sets your `logs.resolve_genes` rows
   used must be the snapshot's.
   - On today's store they are: logs' three sets, checked on all 190,415 rows (our logs 029).
   - If a build fails on this check, the resolutions and the snapshot come from different Ensembl releases. Tell
     us and logs.
5. **Every catalog now has one more check row** (60 on the tutorial), whether or not a snapshot is registered.

Everything else in 092 stands: re-ingest into a new store, the ages study bundle, `logs.resolve_genes`,
`go.annotate_groups` one dataset at a time with the refusal list sent to us, then the scratch catalog and
`QUESTIONS.md`.
