# 118 - aging to dataRepo - 2026-10-27 - DATAREPO-85: when MetaMorpheus #2917 ships, `AllQuantifiedPeptides.tsv` rows can name several sites joined by `|`; your ingester files each under its FIRST site, which states a site the spectra did not settle

## What changes for you

- **Nothing today.** MetaMorpheus #2917 is a draft and in no release. This is a heads-up so the reading is decided
  before the first such search reaches you.
- **What #2917 does** (QuantProject 092, their AGING-D12 to us): label-free quantification of PSMs that share one base
  sequence, one mass and the same modifications at different sites, all in one protein group. One row per peptide and
  set of modifications; `Sequence` is every candidate site's full sequence, joined by `|`. On their islet set that is
  858 rows, 786 with a value. **A `|` row names no site.**
- **Where your ingester meets it:** `dotnet/src/DataRepo.Ingest/Sources/Quant.cs`, `PeptideQuantRows`:

  ```csharp
  var first = sequence.Split('|', 2)[0].Trim();
  var proforma = toProforma(first);
  ```

  So each such row's intensity becomes a `quant_values` row for the FIRST candidate's peptidoform, as if that site had
  been called. Anything reading peptidoform quant by site (occupancy from intensity, site-level contrasts) would read a
  site the spectra did not settle. The same `split('|')[0]` is in the Python `src/datarepo/sources/quant.py`, if that
  still runs anywhere.
- **QuantProject's rule, which we agree with:** keep these rows for protein-level work; skip them for site-level work.

## DATAREPO-85 (ask)

How will the ingester carry a `|` row once #2917 is released? Two readings that fit the rule above, yours to choose:
- (a) a peptidoform feature that names the ambiguity (all candidates, or the base sequence plus the modification set
  with no position) and is marked site-ambiguous, so protein-level readers take it and site-level readers can skip it;
- (b) leave it out of peptidoform quant, if protein-level quant in the catalog never reads peptide rows.

Either way, please not the first candidate's site. QuantProject's DATA-DEFINITIONS (GR-23, their 092) has the
details, and they can tell you when #2917 is released.
