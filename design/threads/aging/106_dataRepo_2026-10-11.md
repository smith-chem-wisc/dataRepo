## DATAREPO-79: the two tables

**`curated_run_design`**, key `run_id`. Your columns, unchanged:
- `run_id` (required): the catalog's run id, `PXD...:<file stem>`, as ptmQtl asked. A run the catalog does not hold is
  refused.
- `individual` (required), `injection`, `fraction`, `pool_size`, `acquisition_batch`;
- `source_reference` (required), `evidence`, `confidence`, `curation_version` (required), as in
  `curated_sample_characteristics`.

**`curated_design_factors`**, key (`run_id`, `factor`). Your columns, plus two:
- `level_value` (number) and `level_unit` (one UO CURIE): A1, the numeric form of `level` for age, dose, time and
  passage. `level` stays the depositor's text.
  - They are named `level_*`, not `value`, because `value` is text in `curated_sample_characteristics`. A number of the
    same name one table over invites a wrong join.
- `is_primary` (boolean, optional): A2, the authors' own comparison. Empty means not stated.

**`not applicable` versus not known (A4).** An empty cell means not known. A reserved word is kept apart from it:
- in a text column (`individual`), the word stays in the column and a computed flag, `individual_reserved`, marks it.
  That is the rule `value_reserved` follows in `curated_sample_characteristics`;
- in a number column (`injection`, `fraction`, `pool_size`), the number is empty and a companion text column
  (`injection_reserved`, `fraction_reserved`, `pool_size_reserved`) holds the word as written.

So a pool's individual and an unfractionated run's fraction are written `not applicable`.

**Checks at build.** Each one refuses the delivery; none is a warning:

  - within a dataset, each factor has at least one `is_reference = true` level and at least one other level;
  - every run in `curated_design_factors` is in `curated_run_design`;
- A3: every run of one sample (through `assays`) carries the same factor rows;
- every `run_id` is a run the catalog holds;
- within a dataset, one factor's level is never marked both reference and not reference.

**Delivery:** through `datarepo study`, in the same YAML that delivers `curated_sample_characteristics`, one file per
