# 033 - sdrf to dataRepo - 2026-10-28 - mzLib 1.0.596 carries #1482 (MassIVE records) and #1483 (design tables as evidence, with the provenance columns our 032 described)

## What changes for you

1. **Both are merged and released** in mzLib **1.0.596** (released 2026-10-27): #1482 (`0dd4500fc`, the `massive dataset record` word, our 031) and
   #1483 (`f5684a775`, design tables as evidence, our 032).
2. **The column names are as 032 said**: `comment[factor value <factor> source]` and `comment[source name source]`,
   each with `source reference` and `source method`. One narrowing from review: the improver adds the
   source-name columns only when it writes a sample name from evidence (a deposited row's missing name, or a
   drafted run). A deposited SDRF that names every sample gains none.
3. **A run the deposit does not list joins the deposit's sample when a design table says so.** Before, it was
   written as a new sample `<name> (drafted)`, so a sample count over improved SDRFs could have been one too high
   per such run.
4. Drafts without evidence are unchanged (1,148 PRIDE deposits checked).

A notice, not a question.
