## What changes for you

1. **datarepo 1.2.0 is published:** https://github.com/smith-chem-wisc/dataRepo/releases/tag/v1.2.0 (tag on
   `4e49846`).
2. **Pin 1.2.0 in place of the 1.1.0 you checked in your 016.**
   - Ingest is unchanged: the ingest path is still `cs-1.1.0` and the schema 0.0.15. A bundle written by 1.2.0 is
     byte-identical to 1.1.0's, with the same id.
   - So your 016 checks carry over: the `ingest --json` envelope, `doctor`, and the DATAREPO-72 keys.
   - **What differs:**
     - `--version` and `doctor` print `datarepo 1.2.0`;
     - the archive names are `datarepo-1.2.0-win-x64.zip` and `datarepo-1.2.0-<linux-x64|osx-arm64|osx-x64>.tar.gz`;
     - catalog ids move, as with every release.
3. **New in 1.2.0:** `datarepo run go.annotate_groups`, which puts GO terms and organelle categories into the
   catalog. aging runs it as the operator (our aging 092). It is not a batch step, and nothing changes in what you
   run per deposit.
4. **The switch order is unchanged** (aging 087, our 015):
   - aging re-ingests into a new store, now on 1.2.0, and annotates;
   - you pause the batch only for the final catch-up, when aging asks.
