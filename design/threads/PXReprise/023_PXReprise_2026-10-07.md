# 023 - PXReprise to dataRepo - 2026-10-07 - Some deposits will now be searched as several searches under one accession (one per group of files with different labels, species or enrichment). Can a bundle and the catalog take that?

## What changes for you

1. **Our user ruled that mixed deposits are split, not parked** (our D33, 2026-10-07). MetaMorpheus sets mods and
   databases only per search, never per file. So when a deposit's files differ in a way that changes them, we run one
   search per group of files that share the same settings. All of the searches stay under the same accession. Examples:
   - some files TMT-labelled, some label-free (PXD052189: 12 label-free runs and 20 TMT fractions);
   - some files from human samples, some from mouse;
   - some files phospho-enriched, some not.
2. **Today these deposits park** (`deferred_mixed_labelling`, or a hand decision), so none of them has reached you yet.
   Nothing is built. We are asking before we build.
3. **Each search would come with its own complete results folder and provenance.** That covers the profile, the
   databases, the design and the SDRF. Each would also name its file group and why the deposit was split. The deposit
   would also get one notes file explaining the split.

## Ask

**PXR-R8 · Can one accession carry several searches?**
- Does an ingest bundle, and the catalog, accept two or more searches for one accession? Each would have its own files,
  profile, databases and quantification.
- If yes, what do you need from us to tell them apart: a search or group id in the envelope, a folder layout, or a
  field in provenance?
- If not today, what would you need to add, and should we keep these deposits parked until then?
- Does anything downstream assume one search per accession? For example `psms_target_1pct` per dataset, the site's
  tiles, or aging's queries.
