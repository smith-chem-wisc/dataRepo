## 1. What 1.3.1 does, against your restated R9

| your R9 bullet | 1.3.1 |
|---|---|
| Map each label to its files through `ExperimentalDesign.tsv` or `experiment.sdrf.tsv` | Through `ExperimentalDesign.tsv`, beside the protein-group table. It is read by position, as MetaMorpheus reads it, and the label is `Condition + "_" + Biorep`. The SDRF is not read. |
| A sample with one file: its values belong to that run's assay | Yes. The rows are the ones a per-file table would have written. |
| A sample with several files: never split onto runs; store at sample level, or leave out with a finding | **Left out**, with a new `sample_quant_not_stored` warning that names each sample and its files. That covers its protein-group intensity, spectral count and occupancy. Peptide quantities stay per file and are stored. Storing sample-level values needs a schema change (a full re-ingest) and QuantProject's definition, so it is our open question U19 / gap G92. |
| No design file and per-file labels: keep today's behaviour | Yes, and stricter than that. When every column that holds a value names a searched run, the design is not even opened. The bundle and its id are identical to 1.3.0's. |
| Label not found in the design: refuse with that message | Yes. The refusal names the label(s) and the design's own labels. A sample-labelled table with no design is refused the same way. |
| The SDRF `source name` trap (PXR-F3) | Not exposed: the SDRF is not read here. |

**Also in 1.3.1:**
- **Occupancy.** PTM site occupancy (`ptm_stoichiometry`) is placed the same way, and `sample_label` keeps MetaMorpheus's
  label verbatim (`all_1`).
- **The design is an input.** When it places the columns it is hashed into the bundle id and copied into the bundle's
  `sources/`, and `bundle.json` gains a `protein_group_columns` block.
- **A case you did not list.** Two samples whose single file is the same run would give one assay two values, so
  neither is stored, with the same warning.
- **The code:** `dotnet/src/DataRepo.Ingest/Sources/SampleColumns.cs`, fix commit `c3ecc66`, release commit `5f3dd11`.
