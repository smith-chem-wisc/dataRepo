## 1 - PXR-D4: the publish step for `examples/first-run`

```
datarepo publish <manifest.yaml> --site <site dir> [--title TEXT] [--purpose TEXT] [--about FILE]
                 [--base-url URL] [--data-url URL] [--study-latest LAYER]
```

- With no accessions named, it loads **every `include` dataset that has a bundle**, and prints
  `skipped  <PXD>: 'include' in the manifest, but no bundle …` for each one that has none. A bare
  `build` refuses on the first such dataset.
- An unchanged store keeps its catalog, so the site comes out byte-identical and a re-run is safe
  after every ingest. The exit status is `0`, or `1` with the reason on stderr.
- It does **not** run engines, load study deliveries you did not name, or upload anything. Pushing
  the site is the operator's step, because it is outward-facing.
- `--purpose` is new. Without it no page claims a question. The generator used to print aging's
  question on every site.

A tested argv for your first-run, from the manifest's own folder:

```
datarepo publish manifest.yaml --site site --title "<your title>" --purpose "<the question>"
```

Docs: [`docs/operating.md`](https://github.com/trishorts/dataRepo/blob/master/docs/operating.md) (the
operator's loop, including GitHub Pages hosting) and
[`docs/cli.md`](https://github.com/trishorts/dataRepo/blob/master/docs/cli.md#datarepo-publish), which
is generated from the parser.

## 3 - PXR-D1: why executables and not a port

A port would re-implement ingest, catalog, MCP and site, and would have to re-earn every correctness
fix. Those fixes live in 530 tests, many written from a defect found on real data. A packaged
binary built in CI from a tag meets your D8 (.NET, git, MetaMorpheus only) with the same code. The
one hard part is pyMzLib's bridge, which is per-platform and has to travel inside each binary. We
will verify each binary by running the tutorial on it, not by building it.

## 5 - For your slides

**One line.** dataRepo turns the search and quantification output of many reanalysed public
proteomics datasets into one versioned, checked, queryable repository. It serves the repository to
AI agents over MCP and to people as a static website.

**The loop** (each step idempotent; the operator runs them, dataRepo ships them):

```
PXReprise search  ->  manifest.yaml (include / hold / exclude)
                  ->  datarepo ingest    one bundle per dataset (Parquet)
                  ->  datarepo publish   one catalog (DuckDB) + a static site
                  ->  datarepo mcp       three tools for agents: describe, search, sql
```

**Guarantees, one per slide bullet:**
- **Nothing is recomputed.** Every count is reconciled against the search engine's own totals, and
  every PSM links to its spectrum by USI.
- **Content-addressed.** A bundle is named by the hash of its inputs, schema and ingester version.
  The same inputs give the same id; a change makes a new bundle beside the old one, so a cited
  result never changes.
- **Every answer is traceable.** Each agent answer carries the `catalog_id` it came from. The id
  comes from the server, never from the query.
- **An empty table is never a "no".** Answers say when a query read a table nobody has delivered.
- **Caveats before counts.** Each dataset's findings (a low ID rate, an SDRF with no biology) show
  before its numbers, on its page and in agent answers.
- **The producer decides what is served.** `exclude` is refused with the producer's own reason.
- **Missing is not zero, and curated is not deposited.** Each has its own representation.

**Scale today** (aging's public site, catalog `c3e8d1e85612ed0c`, built 2026-09-29 by datarepo
0.28.1; https://trishorts.github.io/aging-pipeline/):
- 54 public PRIDE datasets, 1,210 raw files, 33,458,669 MS2 spectra searched;
- 11,395,542 PSMs at 1% FDR;
- 25,554 proteins identified, 13,078 of them in 3 or more datasets (decoys and contaminants
  excluded);
- 533,260 PTM sites of 148 kinds.

**The schema:** 31 core tables, generic to any bottom-up reanalysis and a superset of QPX. A study
adds its own layer beside the core (aging's: sample ages, age effects, curated sample metadata) and
never changes a core table.

**Status:** pre-release, datarepo 0.30.0 and core schema 0.0.13, MIT-licensed. Each instance's
operator licenses its data (aging's is CC BY 4.0).
