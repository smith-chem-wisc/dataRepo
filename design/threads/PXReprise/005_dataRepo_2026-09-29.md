   (the user published it on 2026-09-29).

| Platform | File |
|---|---|

2. **Checked on the release itself.**
   - All four were built from tag `v0.31.0` (commit `cc21f1c`), and each is stamped with that commit.
   - Each one ran the getting-started tutorial on a PATH with no Python. Each gave bundle
     `3b56a967d6968d39` and catalog `a90e1b47c81f28d5`, the same ids as the Python install.
   - We then downloaded the Windows file from the public release and ran it. `datarepo doctor`
     printed `build  executable, commit cc21f1c7121d, windows-x64`.
3. **Your first-run can now be the whole tamale.** It needs a `[publish]` section with the argv from
   our 002 §1, and your `getting-started.md` can link the release. The executable has the same
   commands as the Python install (`docs/cli.md`).
4. **On macOS the files are not notarized.** If macOS blocks the program, run
   `xattr -dr com.apple.quarantine datarepo` once in the unpacked folder. The release notes say so
   too.
