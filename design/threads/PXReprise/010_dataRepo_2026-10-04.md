## What changes for you

1. **The executable stays a full peer of the library.** Every command of 0.32.0 is in it, and you keep your mzLib pin
   and we keep ours.
2. **`datarepo ingest <manifest> <accession> --json` is built** (dataRepo `dd9bd40`, in the C# executable; it ships at
   our first C# release, nothing is released yet).
   - **stdout:** one JSON envelope and nothing else. **stderr:** the human report you log today.
   - **Exit codes:** unchanged. 0 ok, 1 refused, 2 usage.
   - **A count mismatch with the producer is not a refusal.** It exits 0, as in 0.32.0. It shows as a check with
     `"ok": false` and in `mismatches`.
   - **The envelope:**

     ```
     {"datarepo": "<version>", "ok": true, "exit_code": 0, "reasons": [],
      "datasets": [{"accession": "PXD077298", "status": "ingested",
                    "bundle_id": "...", "bundle_path": "...",
                    "tables": {"psms": 407486, ...},
                    "checks": [{"name": "psms_target_1pct", "ok": false, "observed": 237752,
                                "expected": 237767, "source": "results.txt: ..."}, ...],
                    "mismatches": 2, "unresolved_modifications": {...}, "unmatched_runs": {},
                    "findings": ["count_mismatch", ...], "reasons": []}]}
     ```

   - **`status`** is one of four values:
     - `ingested`;
     - `unchanged`: the bundle was already written;
     - `excluded`: the manifest does not say `include`;
     - `refused`: an input was refused; `reasons` holds ingest's own words.

     A crash still prints the envelope, with `error`.
   - A top-level `reasons` covers a manifest that does not load.
3. **Wish 1 is built in the same commit:** `datarepo manifest` refuses a `run_enrichment` map that ingest would refuse.
   - It uses ingest's rules and ingest's own words.
   - It exits 1 and lists every problem, not just the first.
   - It reads the runs where ingest reads them: the run folder's fetch manifest and QC report, minus the files the
     search left out.
   - Where the run folder is not reachable, it checks the values only and says that coverage was not checked.
   - **Tested on aging's live manifest:** both mixed maps pass (PXD077298: 22 runs, 22 mapped). On a copy with one run
     name misspelt and one value changed, it reports all four problems:
     - a value not in the vocabulary;
     - an unknown run;
     - a missing run;
     - a value the dataset did not declare.
