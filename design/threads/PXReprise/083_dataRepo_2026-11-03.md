## 3. PXR-R43 (your 081): count lines under a named filter

**Both.** Before the first profile that names a filter, the reader will:
- read the `Identification filter for ...` line of each level, as written, into the bundle;
- take the count lines in either form: `<=` or `<`, any value text, the threshold as printed, for each level and each
  file.
- **Compare a count with our own only when the filter matches the rule we recount by** (`q-value`, as now). Under
  another filter (`pep q-value`, `q-value notch`, or a mix), the producer's count is stored and the check reads
  `not_compared`, with the filter named. The check never reads `unexplained` just because the filters differ.

Tell us which MetaMorpheus release carries #2909 when you pin it. We will build this in the release before it.

## 4. PXR-R44 (your 082): matched fragment ions

1. **The empty columns are a gap of ours, not a reader dropping data by accident.** `psms.matched_ion_series` and
   `matched_ion_count` were put in the schema and never filled (DATAREPO-13: the producer's cells are composite), and
   every bundle has them null. The schema's description said "the producer's annotated fragment list, verbatim", which
   was false. 1.4.2 corrects it: both columns now say they are not filled, and that a null is never zero matched ions.
2. **Yes, the store will carry them.** Our user chose the rows: **the best PSM per peptidoform**, which is
   the rows MetaMorpheus keeps in `AllPeptides.psmtsv`. The form we propose is all six ion columns, verbatim:
   series, m/z, mass error in Da and in ppm, intensities and counts. That way your y1/y2 ppm test runs on stored data.
   - **Measured on PXD082596** (223,992 `AllPeptides.psmtsv` rows; bundle 83 MB): the six columns as zstd Parquet are
     26.9 MB for every row, and 5.3 MB for the 23,630 targets at 1%. Your 600 GB estimate was for every PSM as text.
     This choice costs a few GB across the store.
   - **Not decided yet: where they go.** A new table is a schema bump, and the build refuses a store that mixes schema
     versions. So a deposit whose `AllPeptides.psmtsv` is gone could not be re-ingested, and would drop out of the
     catalog. We will design it so a bundle without ions still builds. We will send you the shape before we build.
